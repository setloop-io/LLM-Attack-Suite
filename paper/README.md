# LLM-Attack Suite paper

**LLM-Attack Suite: A Unified Red-Team Framework for Privacy Evaluation of Split and Distributed LLM Systems**

`llm-attack-suite.pdf` combines the concise manuscript and its full supplement. `llm-attack-suite-arxiv-source.zip` includes a single top-level `main.tex`, supplementary source, bibliography and all required figures. Extract into an empty folder and compile with pdfLaTeX three times.

The earlier-title preprint is [arXiv:2610.22722](https://arxiv.org/abs/2610.22722). This revised manuscript is prepared as a replacement for arXiv v2 and has not yet been submitted. The repository's v2.0 release does not update arXiv automatically.

The [v2.0 Hugging Face release](https://huggingface.co/datasets/Setloop/The-LLM-Attacker-Unified-Red-Team-Framework-for-Privacy-Evaluation-of-Split-and-Distributed-LLMs/tree/v2.0) retains the existing dataset ID and unchanged scientific evidence and executable-source snapshots. Version v2.0 changes branding, paper packaging and release metadata only; it adds no experiments or runtime changes. The Python package version remains `1.0.0`. The [v1.0 release](https://huggingface.co/datasets/Setloop/The-LLM-Attacker-Unified-Red-Team-Framework-for-Privacy-Evaluation-of-Split-and-Distributed-LLMs/tree/v1.0) remains available with its original paper filenames.

The manuscript and repository README acknowledge Mei et al.'s earlier autonomous-driving framework named LLM-Attacker ([IEEE publication](https://doi.org/10.1109/TITS.2025.3578383)). Historical identifiers in retained evidence refer to this application, now named LLM-Attack Suite.
